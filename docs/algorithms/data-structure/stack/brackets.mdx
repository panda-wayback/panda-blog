# 括号匹配

沿用[栈](./index.mdx)的 LIFO：后出现的左括号，应先被右括号配上。

## 问题

给定只含 `(` 与 `)` 的字符串，判断是否合法：每个右括号都能配上一个尚未匹配的左括号，且最后没有多余左括号。

## 输入

```
(()())
```

## 输出

```
Yes
```

再例：输入 `(()` 应输出 `No`。

## 解题

从左到右扫；`(` → push，`)` → 必须从栈顶 pop。

中途 `)` 时已是空栈，或结束时栈非空 → `No`。

## 实现

```cpp
bool ok(const string& s) {
  vector<char> st;
  for (char c : s) {
    if (c == '(') st.push_back(c);
    else {
      if (st.empty()) return false;
      st.pop_back();
    }
  }
  return st.empty();
}
```
