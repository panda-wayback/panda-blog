## 简述

需要「后放进去的先拿出来」时用栈：只在同一端插入和删除。

## 概念

栈遵守 **LIFO（后进先出）**：唯一出口叫**栈顶**（图中上方）；另一端叫**栈底**（图中下方），最早放进去的在底，最后才能出来。

| 操作 | 做什么 |
|------|--------|
| push | 从上方放入，新元素成为栈顶 |
| pop | 从上方拿走当前栈顶 |
| top | 只看栈顶，不拿走 |
| 空栈 | 不能 pop / top |

先建立空间感：左边是「顶 / 底」，高亮格是本帧刚动到的元素；`↓` 放入，`↑` 取出。

## 实现

数组模拟（`tp` 为栈顶下标，空栈时 $tp=0$）：

```cpp
int st[N], tp = 0;
void push(int x) { st[++tp] = x; }
void pop() { --tp; }
int top() { return st[tp]; }
bool empty() { return tp == 0; }
```

## 教具题

学会上面的图之后，用一道最小题把操作串起来。

### 问题

维护一个整数栈，处理若干操作并输出询问结果：

- `push x`：把 $x$ 放到栈顶  
- `pop`：弹出栈顶（保证栈非空）  
- `top`：输出当前栈顶（保证栈非空）

### 输入

第一行操作数 $m$；随后 $m$ 行，每行一个操作。

```
5
push 1
push 2
top
pop
top
```

### 输出

```
2
1
```

对照前面的图：先压入 `1`、`2`，第一次 `top` 得到 `2`；`pop` 后第二次 `top` 得到 `1`。
