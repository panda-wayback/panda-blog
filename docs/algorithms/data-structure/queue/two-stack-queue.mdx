# 双栈模拟队列

沿用[队列](./index.mdx)的 FIFO，以及[栈](../stack/index.mdx)的 LIFO：入队只进「入栈」；出队从「出栈」弹，空了就把入栈倒过去。

## 问题

用**两个栈**实现队列，支持：

- `enqueue x`：队尾入队  
- `dequeue`：队首出队（保证非空）  
- `front`：查询队首（保证非空）

对一组操作，按序输出每次 `front` 的结果。

## 输入

```
6
enqueue 1
enqueue 2
front
dequeue
front
dequeue
```

## 输出

```
1
2
```

## 解题

设栈 $A$＝队尾侧（只负责入），栈 $B$＝队首侧（只负责出）。

| 操作 | 做法 |
|------|------|
| enqueue $x$ | $A$.push($x$) |
| dequeue / front | 若 $B$ 空：把 $A$ 里元素依次弹出压入 $B$（顺序颠倒，先入的到 $B$ 顶）；再对 $B$ 做 pop / top |

每个元素最多被搬一次，$n$ 次操作均摊 $O(1)$。

对照样例：

1. enqueue 1、2 → $A$ 从底到顶为 $1,2$  
2. front：把 $A$ 倒入 $B$，则 $B$ 顶为 $1$ → 输出 `1`  
3. dequeue：弹出 $B$ 顶的 $1$  
4. front：$B$ 顶为 $2$ → 输出 `2`

## 实现

```cpp
stack<int> in, out;

void enqueue(int x) { in.push(x); }

void shift() {
  if (!out.empty()) return;
  while (!in.empty()) {
    out.push(in.top());
    in.pop();
  }
}

void dequeue() {
  shift();
  out.pop();
}

int front() {
  shift();
  return out.top();
}
```
