## 简述

需要「先排进队的先办完」时用队列：从一端进、从另一端出。

## 概念

队列遵守 **FIFO（先进先出）**：

| 端 / 操作 | 含义 |
|-----------|------|
| 队首 | 出口：最早进来的在这里（图中**左侧**） |
| 队尾 | 入口：新来的排到这里（图中**右侧**） |
| enqueue / push | 从队尾进入 |
| dequeue / pop | 从队首离开 |
| front | 只看队首，不拿走 |
| 空队列 | 不能 pop / front |

相对 [栈](../stack/index.mdx)：栈是同一端进出（后进先出）；队列是两端分工（先进先出）。

图中：左侧标队首，右侧标队尾；`→` 表示入队，`←` 表示出队；高亮为刚动到的元素。

要点：先进入的 `1` 先被看到、先离开；`2` 一直在后面等。单次操作 $O(1)$。

数组模拟时常用队头下标 `ql`、队尾下标 `qr`；只增不减会「假溢出」，可用循环队列（下标取模）缓解——入门先掌握逻辑，循环细节见实现注释。

## 实现

```cpp
int q[N], ql = 0, qr = 0;  // [ql, qr) 左闭右开；空当 ql==qr
void enqueue(int x) { q[qr++] = x; }
void dequeue() { ++ql; }
int front() { return q[ql]; }
bool empty() { return ql == qr; }
// 循环队列：下标改为 (x+1)%N，并保证留一空位区分满/空
```

## 教具题

学会上面的图之后，用一道最小题串操作。

### 问题

维护一个整数队列，处理操作并输出询问：

- `enqueue x`：在队尾加入 $x$  
- `dequeue`：弹出队首（保证非空）  
- `front`：输出队首（保证非空）

### 输入

```
5
enqueue 1
enqueue 2
front
dequeue
front
```

### 输出

```
1
2
```

对照前面的图：先看到的是 `1`；出队后队首变成 `2`。
