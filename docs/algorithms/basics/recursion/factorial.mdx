# 阶乘

沿用[递归](./index.mdx)的两要素，本题换成阶乘。

## 问题

给定非负整数 $n$，求 $n!$（约定 $0!=1$）。

## 输入

```
5
```

## 输出

```
120
```

$5!=120$。

## 解题

概念页教具是「连加」；本题是「连乘」。逻辑仍是终止 + 缩小，只是两格内容不同：

| 要素 | 连加（概念页） | 本题 |
|------|----------------|------|
| 终止 | $n=0$ → $0$ | $n=0$ → $1$ |
| 缩小 | $+\,n$ | $\times\,n$ |

即 $fac(n)=fac(n-1)\times n$。  
$fac(5)=fac(4)\times5=\cdots=120$。注意 $n$ 稍大时要用更大整型。

## 实现

```cpp
long long fac(int n) {
  if (n == 0) return 1;
  return fac(n - 1) * n;
}
```
