## 简述

大问题能拆成更小的同类问题时，用「缩小再拼回来」求答案。

## 概念

递归定清两件事即可（相对 [枚举](../enumerate/index.mdx)：枚举横着试，递归纵着拆）：

| 要素 | 含义 |
|------|------|
| 终止 | 小到何时能直接答 |
| 缩小 | 如何变成更小的同类问题，再拼回本层答案 |

只想**这一层**怎么拆/拼，不必在脑子里一次展开整棵树。

以「求 $1+\cdots+n$」为例：$sum(n)=sum(n-1)+n$，终止 $n=0\to 0$。  
调用时一层压一层（像栈），返回时再一层层加上去：

深度 $O(n)$；$n$ 很大时栈可能不够。子问题大量重复 → 记忆化 / DP。

## 实现

```cpp
int sum(int n) {
  if (n == 0) return 0;       // 终止
  return sum(n - 1) + n;      // 缩小并拼回
}
```

## 教具题

### 问题

给定非负整数 $n$，求 $1+2+\cdots+n$（$n=0$ 时为 $0$）。

### 输入

```
5
```

### 输出

```
15
```

对照上面的逻辑：$sum(5)=sum(4)+5=\cdots=15$。
