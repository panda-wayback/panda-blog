# 递归

递归：用**更小的同类问题**表达当前问题，直到能直接回答。

两要素：**终止条件**、**如何缩小并拼回答案**。只想这一层怎么拆/拼，不必展开整棵调用。

相对 [枚举](./enumerate)：枚举横着试；递归纵着拆。  
例：$sum(n)=sum(n-1)+n$，终止 $n=0$。

## 复杂度与数据范围

| 点 | 说明 |
|----|------|
| 终止 | 必须有 |
| 深度 $O(n)$ | $n\sim10^5$ 时栈可能不够，可改循环 |
| 重复子问题 | 代价可能暴涨 → 记忆化 / DP |

## 实现例子

```cpp
int sum(int n) {
  if (n == 0) return 0;
  return sum(n - 1) + n;
}
```
