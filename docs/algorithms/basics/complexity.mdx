# 复杂度

复杂度：**代价随规模 $n$ 怎么涨**。常见说法 $\log n$、$n$、$n^2$，写作 $O(\log n)$、$O(n)$、$O(n^2)$。选算法时对照数据范围。

## 常见量级

| 说法 | 写法 | 典型来源 |
|------|------|----------|
| 常数 | $O(1)$ | 算式、查表 |
| 对数 | $O(\log n)$ | 二分 |
| 线性 | $O(n)$ | 扫一遍 |
| 线性对数 | $O(n \log n)$ | 排序、分治 |
| $n$ 方 | $O(n^2)$ | 两层枚举 |
| $n$ 立方 | $O(n^3)$ | 三层枚举 |
| 指数 | $O(2^n)$ | 枚举子集 |

嵌套越深幂次越高；「每次减半」多一个 $\log$。图上常写 $O(n+m)$。先后两段取较慢的一档。

## 复杂度与数据范围

约 $10^8$ 次简单运算 / 秒（仅粗估）：

| 复杂度 | $n$ 大约 |
|--------|----------|
| $O(n)$ / $O(n\log n)$ | $10^6$～$10^7$ |
| $O(n^2)$ | $10^3$～$5\cdot10^3$ |
| $O(n^3)$ | $200$～$400$ |
| $O(2^n)$ | $\le 20$ |

空间：额外内存 / 递归深度，常见 $O(n)$、$O(n^2)$。

## 实现例子

```cpp
for (int i = 0; i < n; ++i)
  for (int j = 0; j < n; ++j)
    /* 常数次 → O(n²) */;
```
