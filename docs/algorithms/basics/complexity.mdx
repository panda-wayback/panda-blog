# 复杂度

## 简述

选算法、估能不能跑完时，需要知道代价随规模 $n$ 怎么涨。

## 概念

看循环怎么套、规模怎么缩，写成 $O(\cdot)$：

| 说法 | 写法 | 典型来源 |
|------|------|----------|
| 常数 | $O(1)$ | 算式、查表 |
| 对数 | $O(\log n)$ | 二分（每次减半） |
| 线性 | $O(n)$ | 扫一遍 |
| 线性对数 | $O(n \log n)$ | 排序、分治 |
| $n$ 方 | $O(n^2)$ | 两层枚举 |
| $n$ 立方 | $O(n^3)$ | 三层枚举 |
| 指数 | $O(2^n)$ | 枚举子集 |

嵌套越深幂次越高；「每次减半」多一个 $\log$。先后两段取较慢的一档；图上常写 $O(n+m)$。

粗估约 $10^8$ 次简单运算 / 秒时，大致能承受的 $n$：

| 复杂度 | $n$ 大约 |
|--------|----------|
| $O(n)$ / $O(n\log n)$ | $10^6$～$10^7$ |
| $O(n^2)$ | $10^3$～$5\cdot10^3$ |
| $O(n^3)$ | $200$～$400$ |
| $O(2^n)$ | $\le 20$ |

空间：额外内存 / 递归深度，常见 $O(n)$、$O(n^2)$。

## 教具题

### 问题

给定 $n$，下面双重循环最内层执行多少次？数量级是什么？

```cpp
for (int i = 0; i < n; ++i)
  for (int j = 0; j < n; ++j)
    /* 这里算一次 */;
```

### 输入

```
3
```

### 输出

```
9
```

外层 $3$、内层每次 $3$，共 $n^2$ 次 → $O(n^2)$。  
因此 $n=3000$ 大约还能过；$n=10^5$ 的 $O(n^2)$ 通常过不了。

## 实现

```cpp
for (int i = 0; i < n; ++i)
  for (int j = 0; j < n; ++j)
    /* 常数次 → O(n²) */;
```
