# 贪心入门

import {
  AlgoDiagram,
  ArrayPanel,
} from '@site/src/components/AlgoDiagram';

## 简述

每一步按某个标准选当前看起来最好的，希望最后整体也最优——适合「局部最优能推到全局」的安排类问题。

## 概念

入门最常见形态：

1. 按某关键字**排序**  
2. 从左到右扫，**能选就选**（或每次取当前最大/最小）

活动安排：同一时刻只能做一个活动；要尽量多选。标准是——**谁结束得早优先考虑**，给后面腾时间。

把区间画在时间轴上（格子表示占用的时段；本例只示意排序后的取舍）：

| 活动 | 区间 | 结束时刻 |
|------|------|----------|
| A | $[1,4)$ | $4$ |
| B | $[3,5)$ | $5$ |
| C | $[0,6)$ | $6$ |
| D | $[5,7)$ | $7$ |

按结束时间排序后是 A → B → C → D。维护「上一段结束时刻」$\textit{cur}$：

| 活动 | 判断 | 动作 | $\textit{cur}$ |
|------|------|------|----------------|
| A | 可选 | 选 | $4$ |
| B | $3<4$ | 跳过 | $4$ |
| C | $0<4$ | 跳过 | $4$ |
| D | $5\ge4$ | 选 | $7$ |

选中 A、D，共 $2$ 个。

不是所有题都能贪：换错标准可能得到错解。正确性需最优子结构等保证，入门先掌握「定标准 → 排序/取极值 → 扫一遍」。

复杂度：排序 $O(n\log n)$ + 扫描 $O(n)$。

## 实现

```cpp
struct Seg { int l, r; };
bool cmp(const Seg& a, const Seg& b) { return a.r < b.r; }

int max_activities(vector<Seg> a) {
  sort(a.begin(), a.end(), cmp);
  int ans = 0, cur = INT_MIN;
  for (auto [l, r] : a) {
    if (l >= cur) {
      ++ans;
      cur = r;
    }
  }
  return ans;
}
```

## 教具题

### 问题

给定 $n$ 个活动 $[l_i,r_i)$，同一时刻只能做一个，求最多能选多少个互不重叠的活动。

### 输入

```
4
1 4
3 5
0 6
5 7
```

### 输出

```
2
```

与上面选 A、D 一致。
