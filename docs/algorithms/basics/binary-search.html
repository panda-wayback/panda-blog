二分

二分：在有序或答案单调的区间上，看中间，丢掉不可能的一半。

前提：中间信息能否定左半或右半。无单调性不能硬套。
相对 枚举：有序/单调时，尝试次数降到对数级。

为何是 mid+1\mathrm{mid}+1mid+1 / mid−1\mathrm{mid}-1mid−1​

mid\mathrm{mid}mid 已经比过了：

  • 若 a[mid]=xa[\mathrm{mid}] = xa[mid]=x → 直接结束，不用再搜
  • 若 a[mid]≠xa[\mathrm{mid}] \ne xa[mid]=x → mid\mathrm{mid}mid 本身不是答案，下一轮区间不再包含 mid\mathrm{mid}mid

升序数组里找 xxx 时：

比较结果还能在哪边区间怎么收
a[mid]<xa[\mathrm{mid}] < xa[mid]<x只可能在右边（更大的一侧）l←mid+1l \leftarrow \mathrm{mid}+1l←mid+1（丢掉 mid\mathrm{mid}mid 及左边）
a[mid]>xa[\mathrm{mid}] > xa[mid]>x只可能在左边（更小的一侧）r←mid−1r \leftarrow \mathrm{mid}-1r←mid−1（丢掉 mid\mathrm{mid}mid 及右边）

+1 / -1 就是在说：半段废掉的同时，把已检查的 mid\mathrm{mid}mid 也排除掉。

复杂度与数据范围​

每次约减半 → O(log⁡n)O(\log n)O(logn)（或值域上 O(log⁡V)O(\log V)O(logV)）。nnn 到 10610^6106、10910^9109 量级通常仍可行。
值域上「猜答案再检验」称为二分答案。

实现例子​

int find(const vector<int>& a, int x) {
  int l = 0, r = (int)a.size() - 1;
  while (l <= r) {
    int mid = l + (r - l) / 2;
    if (a[mid] == x) return mid;
    if (a[mid] < x) l = mid + 1;
    else r = mid - 1;
  }
  return -1;
}
