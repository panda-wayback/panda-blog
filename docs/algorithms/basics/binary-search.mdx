# 二分

二分：在**有序**或**答案单调**的区间上，看中间，丢掉不可能的一半。

前提：中间信息能否定左半或右半。无单调性不能硬套。  
相对 [枚举](./enumerate)：有序/单调时，尝试次数降到对数级。

## 为何是 $\mathrm{mid}+1$ / $\mathrm{mid}-1$

$\mathrm{mid}$ **已经比过了**：

- 若 $a[\mathrm{mid}] = x$ → 直接结束，不用再搜
- 若 $a[\mathrm{mid}] \ne x$ → $\mathrm{mid}$ 本身不是答案，**下一轮区间不再包含 $\mathrm{mid}$**

升序数组里找 $x$ 时：

| 比较结果 | 还能在哪边 | 区间怎么收 |
|----------|------------|------------|
| $a[\mathrm{mid}] < x$ | 只可能在右边（更大的一侧） | $l \leftarrow \mathrm{mid}+1$（丢掉 $\mathrm{mid}$ 及左边） |
| $a[\mathrm{mid}] > x$ | 只可能在左边（更小的一侧） | $r \leftarrow \mathrm{mid}-1$（丢掉 $\mathrm{mid}$ 及右边） |

`+1` / `-1` 就是在说：半段废掉的同时，把已检查的 $\mathrm{mid}$ 也排除掉。

## 例子

目标 $17$。$\mathrm{mid}=\lfloor(l+r)/2\rfloor$。

| 下标 | $0$ | $1$ | $2$ | $3$ | $4$ | $5$ | $6$ | $7$ |
|------|-----|-----|-----|-----|-----|-----|-----|-----|
| 值 | $2$ | $3$ | $5$ | $7$ | $11$ | $13$ | $17$ | $19$ |

| 步 | $[l,r]$ | mid | $a[\mathrm{mid}]$ | 比较 | 更新 | 剩余 |
|----|---------|-----|-------------------|------|------|------|
| 1 | $[0,7]$ | $3$ | $7$ | $7<17$ | $l\leftarrow4$（$=3+1$） | $11,13,17,19$ |
| 2 | $[4,7]$ | $5$ | $13$ | $13<17$ | $l\leftarrow6$（$=5+1$） | $17,19$ |
| 3 | $[6,7]$ | $6$ | $17$ | $=17$ | 命中 | 下标 $6$ |

对照第 1 步：$\mathrm{mid}=3$ 已不是答案，且左侧更小，故从 $3+1$ 起继续。未找到时最终 $l>r$。

## 复杂度与数据范围

每次约减半 → $O(\log n)$（或值域上 $O(\log V)$）。$n$ 到 $10^6$、$10^9$ 量级通常仍可行。  
值域上「猜答案再检验」称为二分答案。

## 实现例子

```cpp
int find(const vector<int>& a, int x) {
  int l = 0, r = (int)a.size() - 1;
  while (l <= r) {
    int mid = l + (r - l) / 2;
    if (a[mid] == x) return mid;
    if (a[mid] < x) l = mid + 1;
    else r = mid - 1;
  }
  return -1;
}
```
