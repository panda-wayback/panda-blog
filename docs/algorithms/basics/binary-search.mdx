# 二分

## 简述

在有序或答案单调时快速定位目标，避免从头到尾扫。

## 概念

前提：中间信息能否定左半或右半（无单调性不能硬套）。

取 $\mathrm{mid}=\lfloor(l+r)/2\rfloor$。$\mathrm{mid}$ **已经比过了**：

- 相等 → 结束  
- 否则下一轮区间**不再包含** $\mathrm{mid}$

| 比较结果 | 还能在哪边 | 区间怎么收 |
|----------|------------|------------|
| $a[\mathrm{mid}] < x$ | 右边 | $l \leftarrow \mathrm{mid}+1$ |
| $a[\mathrm{mid}] > x$ | 左边 | $r \leftarrow \mathrm{mid}-1$ |

用升序数组找 $17$ 看区间怎么缩（亮格 = mid，变淡 = 已丢掉）：

未找到时最终 $l>r$。每次约减半 → $O(\log n)$。值域上「猜答案再检验」叫二分答案。

## 实现

```cpp
int find(const vector<int>& a, int x) {
  int l = 0, r = (int)a.size() - 1;
  while (l <= r) {
    int mid = l + (r - l) / 2;
    if (a[mid] == x) return mid;
    if (a[mid] < x) l = mid + 1;
    else r = mid - 1;
  }
  return -1;
}
```

## 教具题

### 问题

给定升序整数数组 $a$（下标从 $0$ 开始）和目标 $x$。  
若存在 $a_i=x$，输出任意一个这样的下标；否则输出 $-1$。

### 输入

```
8
2 3 5 7 11 13 17 19
17
```

### 输出

```
6
```

与上面图解一致。目标为 $10$ 时应输出 `-1`。
