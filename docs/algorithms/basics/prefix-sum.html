前缀和 / 差分

一维前缀和​

简述​

多次询问一段区间的和，不想每次都重新扫过去。

概念​

先算「前 iii 项之和」SSS，区间和用两次前缀相减：

S0=0,Si=Si−1+ai,∑i=lrai=Sr−Sl−1.S_0 = 0,\quad S_i = S_{i-1} + a_i,\quad \sum_{i=l}^{r} a_i = S_r - S_{l-1}.S0​=0,Si​=Si−1​+ai​,i=l∑r​ai​=Sr​−Sl−1​.

以 a=[2,3,5,1,4]a=[2,3,5,1,4]a=[2,3,5,1,4]（下标从 111）为例：

问 [2,4][2,4][2,4]：S4−S1=11−2=9S_4-S_1=11-2=9S4​−S1​=11−2=9（即 3+5+13+5+13+5+1）。

O(n)O(n)O(n) 预处理，单次询问 O(1)O(1)O(1)。和可能超出 int。

实现​

for (int i = 1; i <= n; ++i) S[i] = S[i - 1] + a[i];
auto range_sum = [&](int l, int r) { return S[r] - S[l - 1]; };

一维差分​

简述​

多次把某一段整体加一个数，不想每次扫那段；改完后再看最终数组。

概念​

did_idi​ 表示「从 iii 起往后一直多加多少」；对 ddd 做前缀和就还原出 aaa。

区间 [l,r][l,r][l,r] 加 vvv：只改两点——dl+=vd_l{+}{=}vdl​+=v，dr+1−=vd_{r+1}{-}{=}vdr+1​−=v。

（下标按 1..51..51..5；ddd 的高亮是被改过的位置。）
关系：di=ai−ai−1d_i=a_i-a_{i-1}di​=ai​−ai−1​，差分是前缀和的逆。改、查交错时普通差分不够。

实现​

void add(int l, int r, long long v) {
  d[l] += v;
  if (r + 1 <= n) d[r + 1] -= v;
}
for (int i = 1; i <= n; ++i) a[i] = a[i - 1] + d[i];  // a[0]=0
