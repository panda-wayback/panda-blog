# 枚举

import DocCardList from '@theme/DocCardList';

## 简述

候选不多、没有更好结构时，把可能的答案一个个试过去。

## 概念

枚举只要定清三件事——换题时改的是这三格，不是另起一套想法：

| 要素 | 含义 |
|------|------|
| 候选 | 试哪些东西 |
| 判断 | 什么叫合法 |
| 更新 | 合法时怎么记答案 |

一重约 $O(n)$，双重约 $O(n^2)$（见 [复杂度](../complexity.mdx)）。

## 实现

与三要素一一对应：

```cpp
int ans = 0;
for (int x = 1; x <= n; ++x)   // 候选
  if (x % 3 == 0)               // 判断
    ans = x;                    // 更新（取最大）
```

## 教具题

用「$1\sim n$ 中最大的 $3$ 的倍数」把三要素填实。

### 问题

给定正整数 $n$，求 $1\sim n$ 中最大的 $3$ 的倍数。保证至少存在一个。

### 输入

```
10
```

### 输出

```
9
```

### 对照

| 要素 | 本题 |
|------|------|
| 候选 | $x=1,2,\ldots,n$ |
| 判断 | $x\%3=0$ |
| 更新 | 取更大的 $x$ |

$x$ 扫到 $3,6,9$ 时更新，最后得 $9$。
