# 倍数个数

沿用[枚举](./index.mdx)的三要素，本题只改「更新」。

## 问题

给定正整数 $n$，求 $1\sim n$ 中能被 $3$ 整除的数的**个数**。

## 输入

```
10
```

## 输出

```
3
```

$3,6,9$ 共三个。

## 解题

和概念页教具比：候选、判断不变；要的不再是「最大的那个」，而是「有几个」。

| 要素 | 本题 |
|------|------|
| 候选 | $x=1,\ldots,n$ |
| 判断 | $x\%3=0$ |
| 更新 | 每命中一次，$ans\leftarrow ans+1$ |

扫过 $3,6,9$ 后 $ans=3$。  
（也可公式 $\lfloor n/3\rfloor$；这里练的是枚举怎么改更新。）

## 实现

```cpp
int ans = 0;
for (int x = 1; x <= n; ++x)
  if (x % 3 == 0) ++ans;
```
