# 枚举

枚举：**候选一个个试**，判断是否满足条件。

要定清：候选是什么、如何判断、如何更新答案。  
一重多为 $O(n)$；双重（一对下标 / 两个量）多为 $O(n^2)$。

## 复杂度与数据范围

总代价 ≈ 次数 × 每次检查（见 [复杂度](./complexity)）：

| 形态 | 复杂度 | 数据范围 |
|------|--------|----------|
| 一重 | $O(n)$ | 约到 $10^6$～$10^7$ |
| 双重 | $O(n^2)$ | 约到几千 |
| $n\sim10^5$ 仍双重 | — | 需缩范围或换算法 |

## 实现例子

$1\sim n$ 中最大的 3 的倍数：

```cpp
int ans = 0;
for (int x = 1; x <= n; ++x)
  if (x % 3 == 0) ans = x;
```
