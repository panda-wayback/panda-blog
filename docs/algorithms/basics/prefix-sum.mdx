# 前缀和 / 差分

## 一维前缀和

### 简述

多次询问一段区间的和，不想每次都重新扫过去。

### 概念

先算「前 $i$ 项之和」$S$，区间和用两次前缀相减：

$$
S_0 = 0,\quad S_i = S_{i-1} + a_i,\quad
\sum_{i=l}^{r} a_i = S_r - S_{l-1}.
$$

以 $a=[2,3,5,1,4]$（下标从 $1$）为例：

<AlgoDiagram caption="原数组 a 与前缀和 S；高亮表示累加关系">
  <ArrayPanel
    title="a（下标 1…5）"
    items={[2, 3, 5, 1, 4]}
    indexBase={1}
  />
  <ArrayPanel
    title="S：Sᵢ = Sᵢ₋₁ + aᵢ"
    items={[0, 2, 5, 10, 11, 15]}
    indexBase={0}
    hot={[5]}
    note="S₅=15 是全部前缀和"
  />
</AlgoDiagram>

问 $[2,4]$：$S_4-S_1=11-2=9$（即 $3+5+1$）。

$O(n)$ 预处理，单次询问 $O(1)$。和可能超出 `int`。

### 实现

```cpp
for (int i = 1; i <= n; ++i) S[i] = S[i - 1] + a[i];
auto range_sum = [&](int l, int r) { return S[r] - S[l - 1]; };
```

### 教具题

#### 问题

给定长度为 $n$ 的序列与 $q$ 组询问；每组 $l,r$，求区间和。

#### 输入

```
5 3
2 3 5 1 4
2 4
1 5
3 3
```

#### 输出

```
9
15
5
```

| 询问 | 计算 |
|------|------|
| $[2,4]$ | $S_4-S_1=9$ |
| $[1,5]$ | $S_5-S_0=15$ |
| $[3,3]$ | $S_3-S_2=5$ |

## 一维差分

### 简述

多次把某一段整体加一个数，不想每次扫那段；改完后再看最终数组。

### 概念

$d_i$ 表示「从 $i$ 起往后一直多加多少」；对 $d$ 做前缀和就还原出 $a$。

区间 $[l,r]$ 加 $v$：只改两点——$d_l{+}{=}v$，$d_{r+1}{-}{=}v$。

<AlgoDiagram caption="两次区间加之后的差分数组 d，再前缀和得到 a">
  <ArrayPanel
    title="操作后 d"
    items={[2, 3, 0, -2, -3]}
    indexBase={1}
    hot={[0, 1, 3, 4]}
    note="d₁+=2，d₄-=2；d₂+=3，d₅-=3"
  />
  <ArrayPanel
    title="前缀和 → a"
    items={[2, 5, 5, 3, 0]}
    indexBase={1}
    note="这才是最终数组"
  />
</AlgoDiagram>

（下标按 $1..5$；$d$ 的高亮是被改过的位置。）  
关系：$d_i=a_i-a_{i-1}$，差分是前缀和的逆。改、查交错时普通差分不够。

### 实现

```cpp
void add(int l, int r, long long v) {
  d[l] += v;
  if (r + 1 <= n) d[r + 1] -= v;
}
for (int i = 1; i <= n; ++i) a[i] = a[i - 1] + d[i];  // a[0]=0
```

### 教具题

#### 问题

长度 $n$ 初始全 $0$；$m$ 次 $[l,r]$ 加 $v$；输出最终数组。

#### 输入

```
5 2
1 3 2
2 4 3
```

#### 输出

```
2 5 5 3 0
```

与上图一致。

二维：子矩形和用容斥；二维差分在四角改。
